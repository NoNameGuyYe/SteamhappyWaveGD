# SteamhappyWaveGD
:steamhappy: as the wave in gd

Notice:
If you want to change which wave the texture is on or quality, change the number after dart_ or change uhd (high quality) to hd (medium) or remove it fully (low)
Example: If you want the second wave in the list be the steamhappy wave on medium texture quality, you will set it to dart_2-hd
